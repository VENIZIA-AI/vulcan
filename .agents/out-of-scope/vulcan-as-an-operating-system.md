# VULCAN as an operating system

Decided: 2026-10-24, the owner.

**Why not.** VULCAN is the capital of how agents work: the rules, skills, process and enforcement. It is not a place that takes over per-repo tooling, so `vulcan release`, a shared make and CI layer, `vulcan check`, `vulcan preset smoke`, a version-policy doctor and `vulcan lint` stay out.

**Reconsider if.** A tool is needed by every project in the same shape and no project owns it better.
