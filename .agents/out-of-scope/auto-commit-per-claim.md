# Auto-commit per claim

Decided: 2026-10-25, the owner, approving the agent-work design.

**Why not.** Committing on its own as each claim closes needs `--no-verify` and writes git without the user's word, which V-W-01 forbids. The user decides when to commit.

**Reconsider if.** The git authority model changes so that an agent may commit unasked.
