# Changelog - 2026-10-20

## VULCAN 0.3.2: The Generated Manifest Is Protected From Hand Edits

<Badge type="tip" text="Enhancement" />

**In one line.** `.agents/vulcan.manifest.json` is rendered from the config by `vulcan sync`; an agent can no longer edit it by hand, and `doctor` tells you how to fix one that was edited.

## What changed

- **A hook refuses writes to the manifest.** `guard-manifest` denies the edit tools and shell commands that write, copy onto or remove the file. The message says to edit `.configs/vulcan.config.*` and run `vulcan sync`. Reading the file and `vulcan sync` itself still work. See [Hooks](/references/hooks/).
- **The manifest starts with a `$generated` note.** It reads `by vulcan sync from .configs/vulcan.config.* - do not edit`. atlas and the other readers ignore it.
- **`doctor` explains a stale manifest.** The `manifest` check says the file is generated or edited by hand, and to edit `.configs/vulcan.config.*` and run `vulcan sync`.

## Who is affected

- **A project with a manifest written before 0.3.2.** No action needed. `doctor` still accepts it; the next `vulcan sync` adds the note.
- **A project that edits the manifest by hand.** Edit `.configs/vulcan.config.*` instead and run `vulcan sync`.
- **A project that runs `vulcan sync` after upgrading.** The new hook is added to `.claude/settings.json`.
