# Changelog - 2026-10-22

## VULCAN 0.3.10: init writes a root bunfig.toml with Bun telemetry off

<Badge type="info" text="Improvement" />

**In one line.** A new project gets a root `bunfig.toml` with `telemetry = false`.

## What changed

- **`vulcan init` and `vulcan init --preset` create `bunfig.toml`** at the root with `telemetry = false`. Bun reads the file only from the directory a command runs in, so it belongs at the root.
- **An existing `bunfig.toml` is kept** byte for byte and reported as `kept`; `sync` never touches the file.

## Who is affected

- **New projects.** Nothing to do. Existing projects get no file and no warning; add one by hand if you want telemetry off.
