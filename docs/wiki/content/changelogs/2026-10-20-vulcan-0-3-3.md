# Changelog - 2026-10-20

## VULCAN 0.3.3: init Asks Its Questions in Order

<Badge type="info" text="Bug Fix" />

**In one line.** `vulcan init --preset <npm package>` in a terminal asks the project name, the side folder, the app name and the shared folder in that order, and no longer prints `bun add` between the questions.

## What changed

- **The questions are in order.** `init` asks the project name, fetches the preset, then asks `Backend folder` (or `Frontend folder`), `Name of this backend app` and `Shared code folder`. Before, a published preset asked the project, then the generic `Name of the first app` and the shared folder, and the side folder last.
- **The fetch is one line.** `init` and `add` print `Fetching preset <name>@<range> ...`. The `bun add` output is printed only when the fetch fails.
- **Without a terminal nothing changes.** A missing flag is still refused before the network is used.

## Who is affected

- **Anyone who runs `init --preset` or `add --preset` with a published preset in a terminal.** No action needed; the files are the same.
- **A script that read the `bun add` output from `init` or `add`.** It is not printed on success any more.
