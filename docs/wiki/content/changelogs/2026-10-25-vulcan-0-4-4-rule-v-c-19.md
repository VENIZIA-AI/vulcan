# Changelog - 2026-10-25

## VULCAN 0.4.4: `V-C-19`, group options that serve one concern

<Badge type="tip" text="New Feature" />

**In one line.** Options that serve one concern are one named object, so `{ limit: { default, max }, write: { mode, sharedRows } }` replaces `{ defaultLimit, maxLimit, writeGuard, sharedRows }`.

## What changed

- **`V-C-19` in the base rules.** Two or more options for the same concern live in one object named for it; independent options stay at the top level. A shared prefix or suffix across sibling names (`defaultX` and `maxX`) is the sign of a scattered group. It applies to new code; an existing shape changes when touched. There is no lint.
- **Not in the default `digest.oftenDropped`**; a project can add it.

## Who is affected

Every project. Run `vulcan sync` so the rule reaches `.agents/vulcan.manifest.json`, and commit the manifest.
