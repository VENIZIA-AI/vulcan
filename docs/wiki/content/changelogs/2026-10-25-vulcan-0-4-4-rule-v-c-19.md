# Changelog - 2026-10-25

## VULCAN 0.4.4: `V-C-19`, group options that serve one concern

<Badge type="tip" text="New Feature" />

**In one line.** Options that serve one concern are one named object, so `{ limit: { default, max }, write: { mode, sharedRows } }` replaces `{ defaultLimit, maxLimit, writeGuard, sharedRows }`.

## What changed

- **`V-C-19` in the base rules.** When two or more options serve the same concern they live in one object named for it, not as prefixed siblings; independent options stay at the top level. A shared prefix or suffix across sibling names (`defaultX` and `maxX`, `xGuard` and `xRows`) is the sign of a scattered group. It applies to new code; an existing shape changes when it is touched. Enforcement is soft: no lint.
- **Not in the default `digest.oftenDropped`.** That list holds the rules sessions drop most, and nothing shows this rule is dropped yet; a project can add it.
- **The ID.** `C-19` without the prefix is a project's own rule (this repository's is ISO dates); `V-C-19` is the base rule.

## Upgrading

Run `vulcan sync` so the new rule reaches `.agents/vulcan.manifest.json`, and commit the manifest.
