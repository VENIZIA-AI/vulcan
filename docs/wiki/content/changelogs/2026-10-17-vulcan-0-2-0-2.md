# Changelog - 2026-10-17

## VULCAN 0.2.0-2: the docs-update skill, symbols follow the build

<Badge type="tip" text="New Feature" /> <Badge type="tip" text="Enhancement" /> <Badge type="info" text="Bug Fix" />

**In one line.** Every project gets a docs-update skill, and atlas sees a rebuild without a restart.

## What changed

- **A new shipped skill, `docs-update`.** It updates the docs and the changelog after a code change, with every path read from the manifest, and runs the gates until they pass. `sync` links it.
- **Symbols follow the build.** In repo mode atlas reads the packages' `.d.ts` again when a rebuild changes them, so a changed signature shows up without restarting atlas.
- **`version` reads what runs.** A package pinned only in `overrides` is read beside the package that depends on it first, so a stale root `node_modules` link no longer wins.
- **Contents anchors follow GitHub.** Emphasis markers go, an underscore inside a word stays, and entities are decoded.
- **The server keeps its name.** It is `<project>-atlas` whenever atlas serves a project, whatever sources ride with it.

## Who is affected

- **A heading with emphasis or an entity in a long agent-read file.** Run `vulcan x okf gen` once.
- **Everyone else.** No action needed.
