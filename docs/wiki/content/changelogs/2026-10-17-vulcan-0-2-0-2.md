# Changelog - 2026-10-17

## VULCAN 0.2.0-2: version reads what runs, anchors as GitHub renders them

**Type:** Bug Fix

**In one line.** Two small fixes found while IGNIS and ARDOR adopted 0.2.0-1.

## What changed

- **`version` reads what runs.** A package the project only pins in `overrides` is read beside the
  package that depends on it first. A root `node_modules` link an older direct dependency left behind
  no longer wins.
- **Contents anchors as GitHub renders the heading.** Emphasis markers go (`The _first_ step` is
  `#the-first-step`), an underscore inside a word stays (`snake_case`), and entities are decoded
  (`Tom &amp; Jerry` is `#tom--jerry`).
- **The okf README** describes renderers as project config and modules, not the old registries.
- **Skill evals across models, in the VULCAN repo.** `make skill-evals SKILL=docs-writing
  PROJECT=../ignis` runs a skill's `evals/evals.json` on haiku, sonnet and opus, grades each run with
  opus and writes a report. A repo tool, not shipped to projects. It spends real model quota - run
  `make skill-evals-plan` first.

## Who is affected

- **A heading with emphasis or an entity in a long agent-read file.** Run `vulcan x okf gen` once.
- **Everyone else.** No action needed.
