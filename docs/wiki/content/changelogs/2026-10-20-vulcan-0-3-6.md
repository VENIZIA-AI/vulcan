# Changelog - 2026-10-20

## VULCAN 0.3.6: One Script Standard for Every App

<Badge type="tip" text="Enhancement" />

**In one line.** Backend and frontend apps now share one set of `package.json` scripts, `init` wires the root `dev` script to it, and `doctor` tells you which app departs from it, without failing.

## What changed

- **The standard.** Every app carries `server:dev`, `compile`, `typecheck`, `lint`, `lint:fix`, `test` and `clean`. `dev`, `start`, `build`, `rebuild`, `preview` and `server:prod` are retired; a domain extra such as `migrate:dev` is fine. The new base rule `V-B-05` states it ([Rules](/references/rules)).
- **The root `dev` script runs `server:dev`.** The root `package.json` that `init --preset` writes has `"dev": "bun run --filter '*' server:dev"`. `make dev` still calls it. An app without a `server:dev` script is skipped, not an error.
- **`doctor` notes departures.** For each app it prints one `info` line naming the standard scripts it lacks and the legacy ones it carries. The line never changes the exit code. See [doctor](/references/commands/doctor#scripts).

## Who is affected

- **A project made by an earlier `init`.** Nothing breaks: its root `dev` script still runs `dev` in every app. To adopt the standard, rename the app scripts and change the root script to `bun run --filter '*' server:dev`; `doctor` lists what is left.
- **A framework author.** A preset that still declares `dev` gets an app the new root script skips; rename `dev` to `server:dev`.
- **Everyone else.** Nothing to do.
