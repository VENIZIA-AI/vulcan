# Changelog - 2026-10-17

## VULCAN 0.2.0-4: type-checking through Bun, fewer dependencies

<Badge type="tip" text="Enhancement" />

**In one line.** A tidy-up pass with no behaviour change: a faster type-check and a smaller install.

## What changed

- **VULCAN type-checks with `bun check`.** `make build`, `make typecheck`, `lint-scripts` and the cli pack smoke use `bun check --no-pretty` instead of `tsc --noEmit`. It reports the same errors, including those from options inherited through a tsconfig `extends`. `tsc` stays only where it emits (atlas `dist`).
- **okf moves `typescript` to devDependencies.** `@venizia/vulcan-okf` imported nothing from `typescript` and no longer installs it for its users. `@venizia/vulcan-atlas` still depends on `typescript` and `@venizia/vulcan` depends on atlas, so installing `@venizia/vulcan` still brings `typescript`.
- **atlas drops `@hono/zod-openapi`.** Nothing imported it.
- **Unused internals removed.** okf `normalizeId`, `exampleDirs`, and the `generate/common` barrel (which re-exported the unused type `GeneratedFile`). None was reachable through a package export.

## Who is affected

- **A project depending directly on `@venizia/vulcan-okf` alone that relied on it bringing `typescript`.** Declare `typescript` in your own devDependencies. Projects installing `@venizia/vulcan` still get `typescript` through atlas.
- **Everyone else.** No action needed.
