# Changelog - 2026-10-17

## VULCAN 0.2.0-4: type-checking through Bun, fewer dependencies

**Type:** Enhancement

**In one line.** A tidy-up pass with no behaviour change: a faster type-check and a smaller install.

## What changed

- **VULCAN type-checks with `bun check`.** `make build`, `make typecheck`, `lint-scripts` and the cli
  pack smoke use `bun check --no-pretty` (Bun 1.4.3 or later) instead of `tsc --noEmit`. It reports
  the same errors, including those from options inherited through a tsconfig `extends`. `make build`
  went from 7.7-10.0 s to 2.0-2.8 s. `tsc` stays only where it emits (atlas `dist`).
- **okf no longer installs `typescript` for its users.** It imported nothing from it; it is now a
  devDependency.
- **atlas drops `@hono/zod-openapi`.** Nothing imported it.
- **Unused internals removed.** okf `normalizeId`, `exampleDirs` and the empty `generate/common`
  barrel. None was reachable through a package export.

## Who is affected

- **A project that relied on `@venizia/vulcan-okf` bringing `typescript` along.** Declare `typescript`
  in your own devDependencies.
- **Everyone else.** No action needed: upgrade, then `vulcan sync`.
