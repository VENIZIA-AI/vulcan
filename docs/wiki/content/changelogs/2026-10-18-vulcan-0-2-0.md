# Changelog - 2026-10-18

## VULCAN 0.2.0: The First Stable Release

<Badge type="tip" text="Enhancement" />

**In one line.** 0.2.0 is the code of 0.2.0-9 under a stable version, and the `latest` dist-tag points at it.

## What changed

- **`@venizia/vulcan`, `@venizia/vulcan-okf` and `@venizia/vulcan-atlas` are 0.2.0 on `latest`.** The code is the code of 0.2.0-9 with only the version fields changed.
- **A plain install takes the stable release.** `bun add -d --exact @venizia/vulcan` pins `0.2.0`.
- **The `next` tag stays on 0.2.0-9.** The `next` dist-tag was never moved and remains on 0.2.0-9.

## Who is affected

- **A project on 0.2.0-9.** Pin `0.2.0` and run `vulcan sync`. Nothing else changes. No action needed beyond bumping the version.
- **A project on an older prerelease.** Read the entries from your version up, then pin `0.2.0`.
- **Users running `vulcan upgrade`.** Running `vulcan upgrade` with no argument installs `next` (0.2.0-9), not 0.2.0. Pass the version explicitly: `bun x --no-install vulcan upgrade 0.2.0`.
