# Changelog - 2026-10-18

## VULCAN 0.2.0: The First Stable Release

<Badge type="tip" text="Enhancement" />

**In one line.** 0.2.0 is the code of 0.2.0-9 under a stable version, and the `latest` dist-tag points at it.

## What changed

- **A plain install takes the stable release.** `bun add -d --exact @venizia/vulcan` pins `0.2.0`, and the same holds for `@venizia/vulcan-okf` and `@venizia/vulcan-atlas`.
- **No code change from 0.2.0-9.** Only the version fields differ; `next` stays on 0.2.0-9.

## Who is affected

- **A project on 0.2.0-9.** Pin `0.2.0` and run `vulcan sync`.
- **A project on an older prerelease.** Read the entries from your version up, then pin `0.2.0`.
- **Users running `vulcan upgrade`.** With no argument it installs `next` (0.2.0-9), not 0.2.0. Pass the version: `bun x --no-install vulcan upgrade 0.2.0`.
