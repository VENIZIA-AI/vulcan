# Changelog - 2026-10-18

## VULCAN 0.2.0: the first stable release

**Type:** Enhancement

**In one line.** 0.2.0 is the code of 0.2.0-9 under a stable version, and the `latest` dist-tag points
at it.

## What changed

- **`@venizia/vulcan`, `@venizia/vulcan-okf` and `@venizia/vulcan-atlas` are 0.2.0 on `latest`.** The
  code is the code of 0.2.0-9; only the versions changed.
- **A plain install takes the stable release.** `bun add -d --exact @venizia/vulcan` pins `0.2.0`.
- **The wiki is a site.** The guides and these changelogs are published with GitHub Pages.

## Who is affected

- **A project on 0.2.0-9.** Pin `0.2.0` and run `vulcan sync`. Nothing else changes.
- **A project on an older prerelease.** Read the entries from your version up, then pin `0.2.0`.
- **`vulcan upgrade`.** It still defaults to the `next` dist-tag. Pass the version:
  `bun x --no-install vulcan upgrade 0.2.0`.
