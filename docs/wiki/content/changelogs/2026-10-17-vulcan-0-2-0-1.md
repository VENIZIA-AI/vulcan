# Changelog - 2026-10-17

## VULCAN 0.2.0-1: the minors from the 0.2.0-0 review

<Badge type="info" text="Bug Fix" /> <Badge type="tip" text="Enhancement" /> <Badge type="danger" text="Security" />

**In one line.** Every minor finding of the 0.2.0-0 final review is fixed: errors say what is wrong and where, generated files settle in one run, and atlas sources recover on their own.

## What changed

- **Contents anchors match GitHub.** `_` is kept, repeated headings get `-1`, `-2`, and a link heading uses its text. Run `vulcan x okf gen` once: long files with such headings get new anchors.
- **okf reports instead of aborting.** A broken region names its file: a duplicated or out-of-order marker says "malformed", while a missing marker says "is missing its markers - add `<start>` and `<end>`". One bad changelog or one empty coverage axis is a problem in the list, and an invalid `VULCAN_CONFIG` gets a plain message. A `gen` that changes nothing says `gen: up to date`.
- **okf reserves `contents` and warns on renderer overrides.** A region with id `contents` is an error reserved for the contents list. A module that replaces a built-in renderer emits a warning.
- **Coverage reporting catches axis problems.** The coverage report fails with the axis problems instead of counting an empty axis as covered.
- **`sync --prune` removes only VULCAN's own old commands.** It removes the exact forms earlier releases shipped. A hook you customised stays. A hand-edited shipped hook no longer leaves two guards after an upgrade.
- **The fail-closed hook says what is missing.** It reports `node_modules/@venizia/vulcan` or bun on PATH. Its `bun install` / `bun i` escape allows only a fixed list of 8 flags: `--frozen-lockfile`, `--production`, `-p`, `--no-save`, `--ignore-scripts`, `--force`, `--verbose`, `--silent`. A flag with a value (like `--cwd=x`) no longer passes.
- **`sync` protects skills directories.** `sync` no longer writes through a symlinked skills directory.
- **The release tag sits on the commit it published.** A retry skips a tag that is already there.
- **atlas sources recover.** A failed npm symbol fetch is retried in the background, a release tag pushed later is seen, a broken cache directory is cloned again, and the offline fallback keeps to the ref you asked for. `version` finds packages installed under another package.
- **atlas validates sources and manifests.** `pull --source <name>` with an unknown name is an error listing the known sources, instead of taking the name as a source. atlas validates npm package names read from fetched manifests (which become cache paths and URLs), and cache directory segments are sanitized against `..`.
- **Smaller fixes.** `vulcan x --help`, `would create` under `--dry-run`, D9 for packages outside `packages/`, CRLF frontmatter, and truthful no-history messages.

## Who is affected

- **Projects with long knowledge files.** Run `vulcan x okf gen` after upgrading, then commit the new anchors.
- **Everyone else.** No action needed: `bun x --no-install vulcan upgrade`, then `vulcan sync`.
