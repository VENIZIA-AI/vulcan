# Changelog - 2026-10-20

## VULCAN 0.3.4: A Preset Can Declare the imports of Its App

<Badge type="tip" text="New Feature" />

**In one line.** A preset can set the `imports` field of the app's `package.json`, so apps can use Node subpath imports (`#src/...`) without `tsconfig` `paths`, `tsc-alias` or a Vite alias.

## What changed

- **A new optional preset key, `imports`.** It is an object of strings, for example `{ "#src/*.json": "./src/*.json", "#src/*": "./src/*.js" }`.
- **`init` and `add` write it into the app.** The app's `package.json` gets `imports` with the values exactly as the preset wrote them. A preset without `imports` leaves `package.json` as before. See [Presets](/references/presets).
- **A key without `#` is refused.** The preset is rejected before anything is written, and the message names the key. Only string values are accepted.

## Who is affected

- **Framework authors.** A preset that needs subpath imports should require VULCAN 0.3.4 or later: 0.3.3 and older ignore the key.
- **Everyone else.** No action needed.
