# Changelog - 2026-10-18

## VULCAN 0.2.0-5: many pages per renderer, coverage by resource, unique package keys

<Badge type="tip" text="New Feature" /> <Badge type="tip" text="Enhancement" /> <Badge type="info" text="Bug Fix" /> <Badge type="warning" text="Breaking Change" />

**In one line.** One renderer can write many pages, coverage works for concepts that live elsewhere, and two packages in directories of the same name no longer clash.

## What changed

- **A renderer may render many pages.** `render()` returns one file or an array of files (for example one page per entity). Every page is checked before anything is written. A single object still works.
- **Coverage counts a concept by its `resource`.** A directory an `okf.coverage` axis matches is covered by a concept at `/<axis>/<directory>.md`, or by any concept whose frontmatter `resource` is that directory's path from the root. Applies to `okf coverage` and `okf check --strict`.
- **A repeated package key is an error.** `packages[].dir` is a unique key, not the directory name. A repeated `dir`, a repeated npm `name`, or two live packages at one `path` fails the config.
- **A tag's `<dir>` may hold slashes.** With `atlas.tagPattern: '<dir>/<version>'`, atlas reads `apps/core/0.0.1-0` as directory `apps/core`; the same holds for `atlas.releaseCommit`. `vulcan doctor`'s tag check still accepts only directories without a slash, so it cannot read such tags.

## Who is affected

- **A project that lists the same `dir`, `name` or live `path` twice.** Its config now fails; give each package its own `dir` and set `path`.
- **Everyone else.** No action needed: upgrade, then `vulcan sync`.

## Breaking changes

> [!WARNING]
> A repeated package `dir`, `name`, or live `path` fails config validation.

**Before:**

```typescript
// .configs/vulcan.config.ts
packages: [
  { dir: 'core', name: '@bana/umbras-core', path: 'umbras/core' },
  { dir: 'core', name: '@bana/kits-core', path: 'auroras/kits/core' },
]
```

**After:**

```typescript
// .configs/vulcan.config.ts
packages: [
  { dir: 'umbras-core', name: '@bana/umbras-core', path: 'umbras/core' },
  { dir: 'kits-core', name: '@bana/kits-core', path: 'auroras/kits/core' },
]
```
