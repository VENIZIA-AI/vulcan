# Changelog - 2026-10-17

## VULCAN 0.1.0-2: no IGNIS framework dependency, V-C-02 caps parameters at 5

<Badge type="tip" text="Enhancement" />

**In one line.** Installing VULCAN no longer pulls in `@venizia/ignis-helpers`, and the options-object rule allows a second parameter where one object cannot carry it, capped at 5.

## What changed

- **No IGNIS framework dependency.** `@venizia/vulcan`, `@venizia/vulcan-atlas` and `@venizia/vulcan-okf` no longer depend on an `@venizia/ignis-*` package, so installing VULCAN adds no duplicate helper package and pins no IGNIS release.
- **`V-C-02` reworded.** One options object first, at most 5 parameters. A second parameter is allowed where that object cannot carry it (such as a repository method taking data and query options separately). The cap is a reviewed rule until lint enforcement (`venizia/max-params-own`) ships in `@venizia/dev-configs`.

## Who is affected

- **Projects citing `V-C-02`.** The rule is looser; code with one options object needs no change.
- **Everyone else.** No action needed.
